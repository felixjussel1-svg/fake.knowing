# 🚨 Fake.Knowing - Phishing-Awareness-Trainingstool

Ein interaktives Lernprojekt, das Menschen hilft, Phishing-Scams und Fake-Websites zu erkennen.

## 📖 Über dieses Projekt

**Fake.Knowing** ist ein Trainingsinstrument zur Sensibilisierung von Cybersicherheit. Es funktioniert nach einem einfachen Prinzip:

1. **Benutzer sieht eine realistische Fake-Website** - Sie ähnelt einer echten Bank
2. **Benutzer gibt Daten ein** - Name, E-Mail, Kontonummer, PIN, etc.
3. **WARNUNG!** - Nach dem Absenden erkennt der Benutzer sofort, dass es ein Scam war
4. **Lernen** - Der Benutzer erfährt, worauf er hätte achten können und wie er sich schützt

## 🎯 Ziele

- ✅ Menschen für Phishing-Gefahren sensibilisieren
- ✅ Warnsignale erkennbar machen (verdächtige URLs, unerwartete Anforderungen, etc.)
- ✅ Praktische Tipps zur Vermeidung von Betrügern geben
- ✅ Sicherheitsbewusstsein durch Erfahrung fördern

## 🚀 Wie man es nutzt

1. **Website öffnen**: `index.html` im Browser öffnen
2. **Fake-Formular ausfüllen**: Die Website sieht seriös aus - gib einfach Test-Daten ein
3. **"Daten aktualisieren" klicken**: Das Abenteuer beginnt!
4. **Warnung lesen**: Erfahre, warum das Phishing war
5. **Tipps lernen**: Entdecke, wie du dich in Zukunft schützt

## ⚠️ Warnsignale, die in diesem Projekt gezeigt werden

- ❌ **Verdächtige URL** - Achte auf die echte Domain
- ❌ **Dringende Aufforderung** - "Bitte sofort aktualisieren"
- ❌ **Passwort-Anforderung** - Echte Banken fragen das NICHT
- ❌ **Sensible Daten-Anforderung** - Sozialversicherungsnummer etc.
- ❌ **Generische Ansprache** - Nicht dein Name
- ❌ **Unprofessionelles Design** - Rechtschreibfehler, alte Grafiken

## 🛡️ Schutztipps (aus dem Projekt)

✓ **URL überprüfen** - https:// + richtige Domain  
✓ **Bank direkt kontaktieren** - Bei Zweifeln anrufen  
✓ **Niemals sensitive Daten eingeben** - PIN, Passwörter gehören nicht ins Web  
✓ **Starke Passwörter** - Unterschiedlich für jede Website  
✓ **Zwei-Faktor-Authentifizierung** - Extra Sicherheitsebene  
✓ **Skeptisch sein** - Vertrau deinem Bauchgefühl!  
✓ **Verdächtige E-Mails melden** - An deine Bank oder Polizei
