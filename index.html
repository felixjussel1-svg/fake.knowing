⚠️ REAL ATTACKS OFTEN USE:

• Fake Windows Update notifications • Email attachments that run PowerShell scripts • Command Prompt windows that pop up unexpectedly • Downloaded scripts from suspicious sources • Social engineering (pretending to be support staff) • Requests to run commands you don't understand

✓ HOW TO PROTECT YOURSELF:

  • Never enter sensitive data into unsolicited popups
  • Verify requests by calling official support directly
  • Check the script source before running PowerShell scripts
  • Keep Windows and security software updated
  • Use strong, unique passwords for important accounts
  • Enable two-factor authentication where possible
  • Be suspicious of unsolicited security warnings
  • Report suspicious scripts to your IT department
